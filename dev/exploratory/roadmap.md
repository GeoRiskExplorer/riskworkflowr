# riskworkflowr roadmap

## Priority improvements

1. Review and likely deprecate `risk_calc_location_quotient()`.
2. Design grouped/category SMR workflow.
3. Create `risk_identify_distinctive_category()` or similar.
4. Return highest and optional lowest distinctive category per unit.
5. Add low-count thresholds and interpretation flags.
6. Enable `map_risk_choropleth()` to map highest SMR category fields.
7. Add small packaged spatial demo datasets.
8. Add pre-made demo hex/H3 cells.
9. Improve vignettes with real spatial examples.
10. Add workflow diagrams.
11. Improve formal citation of applied methods, assumptions, limitations, and alternative/future methods.
12. Add badges, logo, pkgdown polish, and NEWS.md.
